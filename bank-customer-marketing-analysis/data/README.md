# Data folder

- `raw/`: place the downloaded source file `bank-full.csv` here. Run `python scripts/download_data.py` to download from UCI automatically.
- `processed/`: cleaned data is generated by `python run_pipeline.py`.

CSV data files are ignored by Git to keep the repository focused on code and documentation. Do not edit the raw file manually; all transformations are reproducible in `src/common.py` and `scripts/02_preprocess.py`.
