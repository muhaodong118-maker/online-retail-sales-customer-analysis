# 分析计划

## 业务目标

识别公开银行电话营销数据中，不同客群和营销联络特征与定期存款认购结果之间的关联，为后续营销分组、联系安排与测试设计提供分析依据。

## 关键问题

1. 总体营销记录量、认购记录量和转化率是多少？
2. 不同职业、年龄组、余额区间和贷款状态的转化表现有何差异？
3. 不同联系渠道、月份与本次活动联系频次的表现有何差异？
4. 历史营销结果与当前认购表现之间有什么关联？
5. 如何把分析发现转化为可验证的经营试验，而不是直接认定因果关系？

## 指标口径

- 营销记录数：当前筛选范围内的记录行数，不是去重客户数。
- 认购记录数：`y = yes` 的行数。
- 未认购记录数：`y = no` 的行数。
- 转化率：认购记录数 / 总营销记录数 × 100%。
- 客群转化率：某客群中 `y = yes` 的比例；报告时同时展示该组样本量。

## 分析边界

- 公开样本来自葡萄牙银行电话营销，不代表中国银行经营现状。
- 无客户唯一 ID，不能准确计算独立客户数或客户重复触达链路。
- 数据没有产品购买金额、存款余额变化、成本、收入或完整交易流水，不能直接计算真实营销 ROI、增量收入或客户生命周期价值。
- 分组转化率是描述性关联，不足以证明年龄、职业或渠道导致了认购差异。
- `duration` 是通话结束后才能知道的字段，不用于通话前营销优先级制定。
- 小样本分组的转化率容易波动，结论需同时检查样本量。
