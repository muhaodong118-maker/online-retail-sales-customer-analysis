# 数据字典

数据源：UCI Machine Learning Repository — Bank Marketing，使用旧版 `bank-full.csv`。

该文件包含 45,211 条记录、17 个字段。每一行表示一个营销记录；数据不含可用于识别独立客户的客户 ID，因此项目不会把记录数表述为去重客户数。

| 字段 | 含义 | 类型/注意事项 |
|---|---|---|
| `age` | 客户年龄 | 整数 |
| `job` | 职业类别 | 分类变量；`unknown` 作为独立类别保留 |
| `marital` | 婚姻状态 | 分类变量 |
| `education` | 教育水平 | 分类变量；含 `unknown` |
| `default` | 是否有信用违约记录 | yes/no 类别 |
| `balance` | 平均年度余额 | 数值；负余额不自动删除 |
| `housing` | 是否有住房贷款 | yes/no 类别 |
| `loan` | 是否有个人贷款 | yes/no 类别 |
| `contact` | 本次营销联系渠道 | 分类变量 |
| `day` | 本次联系日期中的日 | 1–31 的日号，不应直接当作完整日期 |
| `month` | 本次联系月份 | 分类变量 |
| `duration` | 本次电话持续时间（秒） | 只有通话结束后才知道；不能用于通话前的客户优先级判断 |
| `campaign` | 本次营销活动中联系客户的次数 | 整数 |
| `pdays` | 上一次营销联系后经过的天数 | 原数据中小于 0 表示未在此前营销活动中联系 |
| `previous` | 此前营销活动的联系次数 | 整数 |
| `poutcome` | 上一次营销活动结果 | 分类变量；`unknown` 需要单独解释 |
| `y` | 本次活动是否认购定期存款 | 目标字段 yes/no |

## 项目派生字段

- `target`：`y=yes` 转为 1，`y=no` 转为 0。
- `age_group`：按 18–24、25–34、35–44、45–54、55–64、65+ 分组；超出预期范围或缺失值标为 `unknown`。
- `balance_segment`：负余额、0–999、1,000–4,999、5,000+。
- `campaign_group`：本次活动联系 1 次、2 次、3 次、4–5 次、6 次及以上。
- `previous_contacted`：`pdays < 0` 标记为此前未联系，否则标记为此前联系过。

清洗规则以可解释性为主。`unknown` 不直接替换为众数，负余额不自动删除，重复行先报告而不自动删除；处理方式在业务解释前需要进一步检查。
